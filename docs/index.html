01 // THE EXPERIENCE

Terminal art with a pulse.

Omarcharium treats character cells as a living medium: motion, color, depth, and restraint instead of a looping video or static effect.

01

Distinct life

Neon tetras school. Bettas trail silk-like fins. Puffers drift. Angels rise through the water column. Every species has its own visual and motion grammar.

02

Layered habitat

Plain depth, pelagic fields, and local raster images sit beneath independently animated current and depth effects.

03

Chromatic depth

Lagoon, Midnight, Coral, and Phosphor palettes recolor the complete habitat without flattening species identity.

04

Generated sound

Filtered water flow and bubble chirps stream directly to PipeWire with independent channel controls. One monitor leads; others stay silent.

02 // CONTROL ROOM

Every current is yours.

Click the tray icon to tune exact populations, backdrops, ambience, and surface controls; right-click for concise actions and bug reporting. The screensaver is text-free by default; enable show status display for the header, dismissal hint, and backdrop notices. Changes persist atomically and apply to the next immersion.

Made for Omarchy, not merely launched by it.

04 // INSTALL

One command to the waterline.

Requires current Omarchy Quattro and Python 3.11+. No pip, npm, compiler, installer hook, or privileged write.

$ omarchy plugin add https://github.com/DailenG/omarcharium --enable
